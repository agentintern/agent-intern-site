# Contributing

A person maintains this project, and Claude Code writes much of the code.

- Open an issue before a large change.
- Keep tests green: `npm test`, `npm run typecheck`, `npm run lint`.
- Don't add dependencies without a reason, and keep third-party code out of the repo.
- Nothing here may sign a transaction, and nothing may start a shift without a person.
- There's no reward of any kind for contributing.

The game has its own repo. Its source changes go through the gate.
